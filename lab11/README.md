1. Схема иерархии
BR
└── штат
    └── город

2. Пример path

В рекурсивном запросе поле path используется для хранения пути от начального узла до текущего.

Для прямого обхода от штата CE вниз пример path:

CE
CE -> Fortaleza

Для обратного обхода от города вверх пример path:

Fortaleza
Fortaleza -> CE
Fortaleza -> CE -> Brazil

path показывает последовательность узлов, пройденных во время рекурсивного обхода.

3. Базовая часть рекурсивного CTE

Для обхода поддерева варианта 9 начальным узлом является штат CE:

where node_id = 'ST:CE'

В базовой части для него устанавливается:

depth = 0

То есть штат CE считается нулевым уровнем рекурсивного обхода.

Для обратного рекурсивного запроса базовая часть выбирает конкретный город.

Например:

CITY:CE:fortaleza

Именно с этого узла начинается движение вверх по иерархии.

4. Рекурсивная часть

Рекурсивная часть использует строки, полученные на предыдущем шаге, и добавляет связанные с ними узлы.

При обходе вниз используется условие:

g.parent_id = s.node_id

То есть для текущего узла ищутся все строки, у которых он указан как родитель.

Например:

ST:CE
→ CITY:CE:fortaleza
→ CITY:CE:caucaia

Для каждого нового уровня значение depth увеличивается на единицу:

depth + 1

При обратном обходе используется условие:

g.node_id = a.parent_id

В этом случае выполняется переход от текущего узла к его родителю.

Например:

CITY:CE:fortaleza
→ ST:CE
→ BR

Рекурсивный процесс продолжается до тех пор, пока новые связанные строки больше не находятся.
